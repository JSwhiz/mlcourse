# Topic 05 · Ensembles & Random Forests

[![Notebooks CI](https://github.com/JSwhiz/mlcourse/actions/workflows/notebooks-ci.yml/badge.svg)](https://github.com/JSwhiz/mlcourse/actions/workflows/notebooks-ci.yml)

This topic studies why combining unstable learners can improve generalization, how bagging reduces variance, how random forests decorrelate trees, and what feature importance can and cannot tell us.

## Notebooks
- [`01_bagging_random_forest.ipynb`](./notebooks/01_bagging_random_forest.ipynb) — single tree vs bagging vs random forest.
- [`02_feature_importance.ipynb`](./notebooks/02_feature_importance.ipynb) — impurity importance, permutation importance and validation.

Reasoning: `variance problem → ensemble mechanism → OOB/CV evidence → interpretation limits`.
