# Визуализация — Как выбирать график

Главный вопрос перед построением графика:

> **Что именно я хочу проверить?**

Не начинаю с «хочу построить heatmap». Начинаю с аналитического вопроса.

## Быстрая карта

| Вопрос | Тип данных | Первый график |
|---|---|---|
| Как выглядит распределение? | 1 числовой | histogram / KDE |
| Есть ли крайние значения? | 1 числовой | boxplot |
| Как устроена плотность распределения? | числовой | violinplot |
| Сколько объектов в категориях? | категориальный | countplot |
| Как числовой признак отличается между группами? | числовой + категория | boxplot / violinplot |
| Связаны ли два числовых признака? | 2 числовых | scatterplot |
| Какие числовые признаки движутся вместе? | много числовых | correlation heatmap |
| Как меняется доля класса внутри категории? | категория + target | crosstab + grouped plot |

## Правильный паттерн

```text
гипотеза
→ график
→ визуальное наблюдение
→ числовая проверка
→ вывод
```

Пример:

«Кажется, клиенты с international plan уходят чаще» → `countplot` → визуально churn заметно выше → считаю `crosstab(..., normalize='index')` → фиксирую разницу в долях.

## Что считаю ошибкой

- строить десять графиков без вопроса;
- выбирать график только потому, что он красивый;
- сравнивать абсолютные counts при сильно разных размерах групп;
- делать причинный вывод из визуальной ассоциации;
- считать выброс автоматически ошибкой данных.
