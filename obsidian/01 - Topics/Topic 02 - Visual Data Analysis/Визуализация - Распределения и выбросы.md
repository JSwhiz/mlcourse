# Визуализация — Распределения и выбросы

## Histogram

Показывает, как наблюдения распределены по диапазонам значений.

Смотрю на:
- центр распределения;
- ширину;
- асимметрию;
- несколько пиков;
- длинные хвосты;
- пустые интервалы.

Количество bins влияет на картину, поэтому не стоит интерпретировать один вариант как абсолютную истину.

## KDE

Сглаженная оценка плотности. Удобна для сравнения формы распределений, но сглаживание тоже может скрывать или создавать визуальные детали.

## Boxplot

Коротко показывает:
- медиану;
- Q1 и Q3;
- IQR;
- значения за пределами усов.

Важно: точка за усами — это **потенциальный выброс**, а не автоматически плохая запись.

## Violinplot

Совмещает идею boxplot с формой оценённой плотности. Полезен, когда важно видеть не только квартильные границы, но и форму распределения внутри группы.

## Как проверять визуальный вывод

После графика использую:

```python
s.describe()
s.quantile([0.01, 0.25, 0.5, 0.75, 0.99])
```

Для сравнения групп:

```python
df.groupby('group')['feature'].agg(['mean', 'median', 'std', 'count'])
```
