# NumPy — основы

[[Topic 01 - Overview]] · [[Topic 01 - Подробная выжимка]]

## Зачем нужен NumPy

NumPy — базовый слой численных вычислений в Python. Его главная структура — `ndarray`: многомерный однородный массив данных.

Ключевая идея: вместо обработки каждого элемента Python-циклом мы стараемся описать операцию сразу над всем массивом.

```python
import numpy as np

x = np.array([1, 2, 3, 4])
x ** 2
```

## Что нужно смотреть у массива

```python
x.shape   # форма
x.ndim    # число измерений
x.dtype   # тип элементов
x.size    # число элементов
```

`shape` особенно важен: огромное количество ошибок в ML связано не с математикой, а с несовместимыми размерностями.

## Индексация и срезы

```python
A = np.arange(12).reshape(3, 4)

A[0]       # первая строка
A[:, 1]    # второй столбец
A[1:, 2:]  # подматрица
```

Важно помнить: срез NumPy часто является **представлением (view)** исходного массива, а не независимой копией.

## Булевы маски

```python
A[A > 5]
A[A % 2 == 0]
```

Это прямой аналог фильтрации в Pandas. Условие создаёт массив `True/False`, который используется для выбора элементов.

## Broadcasting

Broadcasting позволяет выполнять операции между массивами совместимых форм без ручного копирования данных.

```python
A = np.arange(12).reshape(3, 4)
offset = np.array([10, 20, 30, 40])
A + offset
```

Вектор `offset` виртуально распространяется по строкам матрицы.

### Практическое правило

Сравнивай формы справа налево. Размерности совместимы, если они:

- одинаковы;
- либо одна из них равна `1`.

## `axis`

```python
A.mean(axis=0)  # результат для каждого столбца
A.mean(axis=1)  # результат для каждой строки
```

Удобная модель:

- `axis=0` — «схлопываем строки», остаются столбцы;
- `axis=1` — «схлопываем столбцы», остаются строки.

## Векторизация

Вместо:

```python
result = []
for value in x:
    result.append(value ** 2 + 3 * value)
```

лучше:

```python
result = x ** 2 + 3 * x
```

Преимущества:

- меньше кода;
- проще читать;
- меньше мест для ошибок;
- обычно существенно быстрее.

## Нормализация

Один из типичных численных паттернов:

```python
z = (x - x.mean()) / x.std()
```

Получаем z-score: насколько каждое значение удалено от среднего в единицах стандартного отклонения.

## Что запомнить

1. NumPy работает с массивами, а не с отдельными числами.
2. Перед операцией проверяй `shape`.
3. Булевы маски — основа фильтрации.
4. `axis` определяет направление агрегации.
5. Broadcasting позволяет убрать множество циклов.
6. Векторизация — базовый стиль численного Python.
