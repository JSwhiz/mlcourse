# Topic 01 — подробная выжимка по Pandas

[[ML Course]] · [[Topic 01 - Overview]] · [[Pandas - Quick Reference]]

## 1. Зачем нужен Pandas

`pandas` — библиотека Python для работы с табличными данными. Главная структура — `DataFrame`: таблица со строками, именованными столбцами и индексом. Один столбец обычно представлен объектом `Series`.

Главная идея Topic 01: аналитическая задача почти всегда сводится к цепочке:

> **загрузить → осмотреть → выбрать → отфильтровать → преобразовать → сгруппировать → посчитать → интерпретировать.**

Pandas особенно удобен тем, что большинство операций выполняются сразу над целыми столбцами. Это называется **векторизованным подходом** и обычно предпочтительнее ручных Python-циклов.

## 2. Загрузка данных

```python
import pandas as pd

df = pd.read_csv("data.csv")
```

После загрузки нельзя сразу переходить к выводам. Сначала нужно понять таблицу.

```python
df.head()       # первые строки
df.tail()       # последние строки
df.shape        # (число строк, число столбцов)
df.columns      # названия столбцов
df.dtypes       # тип каждого столбца
df.info()       # типы + количество непустых значений
df.describe()   # статистики числовых признаков
```

### Что проверять первым делом

- сколько строк и признаков;
- что означает каждая строка;
- что означает каждый столбец;
- правильные ли типы данных;
- есть ли пропуски;
- нет ли невозможных или подозрительных значений;
- какие признаки числовые, категориальные, булевы, временные.

## 3. Series и DataFrame

```python
age = df["age"]              # Series
subset = df[["age", "sex"]] # DataFrame
```

`Series` можно представить как один именованный столбец с индексом. `DataFrame` — набор согласованных Series с общим индексом строк.

Полезная модель:

```text
index | age | sex    | salary
------+-----+--------+-------
0     | 39  | Male   | <=50K
1     | 50  | Male   | <=50K
2     | 38  | Male   | <=50K
```

Индекс — не номер строки «на экране», а отдельная система меток.

## 4. Выбор данных: `[]`, `.loc`, `.iloc`

### По имени столбца

```python
df["age"]
df[["age", "salary"]]
```

### `.loc` — по меткам и условиям

```python
df.loc[df["sex"] == "Female", "age"]
```

Читается почти как предложение: «в строках, где пол Female, взять столбец age».

### `.iloc` — по позициям

```python
df.iloc[:5, :3]
```

Это первые 5 строк и первые 3 столбца независимо от их названий.

**Правило:** если логика анализа основана на смысле признаков и условиях, чаще нужен `.loc`; если нужны физические позиции — `.iloc`.

## 5. Булевы маски и фильтрация

```python
df["age"] >= 30
```

возвращает Series из `True/False`. Эту маску можно использовать для выбора строк:

```python
df[df["age"] >= 30]
```

Несколько условий:

```python
df[(df["age"] >= 30) & (df["sex"] == "Female")]
df[(df["salary"] == ">50K") | (df["hours-per-week"] > 60)]
df[~df["native-country"].isin(["United-States", "Canada"])]
```

Операторы:

- `&` — И;
- `|` — ИЛИ;
- `~` — НЕ.

Каждое условие при комбинировании нужно заключать в скобки.

## 6. Очень полезный приём: среднее булевой маски

В Python/Pandas `True` ведёт себя как `1`, `False` — как `0`. Поэтому:

```python
(df["native-country"] == "Germany").mean()
```

даёт **долю** строк, удовлетворяющих условию.

Это один из самых удобных приёмов для бинарных событий:

```python
share = df["salary"].eq(">50K").mean()
```

Если нужен процент:

```python
share * 100
```

## 7. Категориальные признаки и `value_counts()`

```python
df["sex"].value_counts()
```

показывает абсолютные частоты категорий.

```python
df["sex"].value_counts(normalize=True)
```

показывает доли.

Это один из первых методов, которые стоит применять к категориальному признаку.

## 8. Описательные статистики

Для числового столбца:

```python
df["age"].mean()
df["age"].median()
df["age"].std()
df["age"].min()
df["age"].max()
```

### Среднее и медиана

Среднее чувствительно к выбросам. Медиана — значение, разделяющее упорядоченные наблюдения пополам, и обычно устойчивее к экстремальным значениям.

### Стандартное отклонение

`std()` показывает характерный масштаб разброса значений вокруг среднего. Само по себе среднее без оценки разброса часто недостаточно.

## 9. `groupby`: split → apply → combine

`groupby` — одна из важнейших идей Pandas.

```python
df.groupby("salary")["age"].mean()
```

Логически происходит три шага:

1. **split** — строки делятся по `salary`;
2. **apply** — для каждой группы считается средний `age`;
3. **combine** — результаты собираются в одну структуру.

Несколько статистик:

```python
df.groupby("salary")["age"].agg(["mean", "median", "std", "min", "max"])
```

Несколько ключей группировки:

```python
df.groupby(["race", "sex"])["age"].describe()
```

## 10. `agg()`

`agg()` позволяет явно указать, какие агрегаты нужны:

```python
df.groupby("category").agg({
    "value": ["mean", "median", "max"],
    "id": "count",
})
```

Это удобнее, чем создавать много отдельных выражений.

## 11. Строковые методы

Pandas умеет применять строковые операции ко всему Series:

```python
df["marital-status"].str.startswith("Married")
df["name"].str.lower()
df["text"].str.contains("python", case=False)
```

Не нужно писать цикл по каждой строке.

## 12. Сортировка

```python
df.sort_values("age")
df.sort_values("age", ascending=False)
df.sort_values(["salary", "age"], ascending=[True, False])
```

Сортировка полезна для поиска экстремальных наблюдений и подготовки читаемого результата.

## 13. Пропуски

```python
df.isna().sum()
```

показывает количество пропусков по столбцам.

Основные действия:

```python
df.dropna()
df.fillna(value)
```

Но нельзя автоматически удалять или заполнять пропуски. Сначала нужно понять, **почему** они появились и что они означают.

## 14. `copy()` и безопасные изменения

После фильтрации, если планируется добавлять или менять столбцы, удобно явно сделать копию:

```python
men = df[df["sex"] == "Male"].copy()
men["married"] = men["marital-status"].str.startswith("Married")
```

Так код явно показывает, что создаётся самостоятельная рабочая таблица.

## 15. Переформатирование результата

После группировки иногда получается многоуровневый индекс. `unstack()` переносит один уровень индекса в столбцы:

```python
(
    df.groupby(["native-country", "salary"])["hours-per-week"]
      .mean()
      .unstack("salary")
)
```

Так результат часто легче читать и сравнивать.

## 16. Что показал анализ UCI Adult

В практической работе Topic 01:

- мужчин: **21 790**, женщин: **10 771**;
- средний возраст женщин — около **36.86 года**;
- доля Германии — около **0.42%**;
- средний возраст группы `>50K` — около **44.25**, группы `<=50K` — около **36.78**;
- высокие доходы встречаются и без перечисленного высшего образования;
- максимальный возраст мужчины `Amer-Indian-Eskimo` — **82 года**;
- доля `>50K` среди женатых мужчин выше, чем среди неженатых;
- максимум рабочего времени — **99 часов/неделю**;
- 99 часов работают **85 человек**, и лишь около **29.4%** из них имеют доход `>50K`.

Эти выводы демонстрируют важный принцип: **описательная статистика показывает структуру данных, но не доказывает причинно-следственные связи**.

## 17. Типичные ошибки начинающего

### 1. Использовать циклы там, где есть векторизация

Плохо:

```python
result = []
for value in df["age"]:
    if value > 30:
        result.append(value)
```

Лучше:

```python
df.loc[df["age"] > 30, "age"]
```

### 2. Считать абсолютные количества вместо долей

Если группы разного размера, сравнение количества `>50K` может вводить в заблуждение. Нужно сравнивать долю внутри каждой группы.

### 3. Делать причинный вывод из корреляции или групповых средних

То, что группа A в среднем старше и имеет больший доход, не означает, что возраст сам по себе является причиной высокого дохода.

### 4. Игнорировать пропуски и типы

Строка `"42"` и число `42` — разные типы. Ошибочный тип способен сломать сортировку, агрегирование и сравнения.

### 5. Использовать chained indexing

Вместо:

```python
df[df["sex"] == "Female"]["age"]
```

для явного выбора предпочтительнее:

```python
df.loc[df["sex"] == "Female", "age"]
```

## 18. Как мыслить при решении задачи

Допустим, вопрос: «Каков средний возраст женщин?»

Не нужно вспоминать готовую строку кода. Разложи вопрос:

1. объект анализа — строки с женщинами;
2. условие — `sex == "Female"`;
3. интересующий признак — `age`;
4. операция — среднее.

Отсюда естественно получается:

```python
df.loc[df["sex"] == "Female", "age"].mean()
```

Такой подход масштабируется на гораздо более сложные задачи.

## 19. Минимум, который должен остаться в памяти

```python
# осмотр
df.head()
df.info()
df.describe()

# выбор
df["col"]
df[["a", "b"]]
df.loc[condition, "col"]
df.iloc[rows, cols]

# фильтрация
df[df["x"] > 0]
df[(cond1) & (cond2)]

# категории
df["category"].value_counts()

# статистика
df["x"].mean()
df["x"].median()
df["x"].std()

# группы
df.groupby("group")["x"].mean()
df.groupby("group")["x"].agg(["mean", "median", "max"])

# пропуски
df.isna().sum()
```

## 20. Главное из Topic 01

> Pandas — это не набор команд для запоминания. Это язык, на котором аналитический вопрос переводится в операции над таблицей.

Хороший анализ состоит из четырёх уровней:

1. **понимание данных** — что лежит в таблице;
2. **корректная выборка** — какие наблюдения действительно отвечают вопросу;
3. **правильный расчёт** — какая статистика нужна;
4. **интерпретация** — что число означает и чего оно не доказывает.
