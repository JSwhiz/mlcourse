# Titanic — практика Pandas

[[Topic 01 - Overview]] · [[Pandas - Indexing and Filtering]] · [[Pandas - GroupBy and Aggregations]]

## Зачем эта практика

Titanic удобен как учебный набор данных: в нём есть числовые и категориальные признаки, пропуски, бинарная целевая переменная и естественные вопросы к группам пассажиров.

Главный шаблон анализа:

> **вопрос → нужная выборка → метрика → интерпретация**

## Первичный осмотр

```python
df.shape
df.head()
df.dtypes
df.isna().sum()
df.describe()
```

Перед любыми выводами нужно понять:

- сколько строк и признаков;
- какие признаки категориальные;
- где есть пропуски;
- какие значения являются кодами категорий;
- что означает целевая переменная.

## Фильтрация

Пример: женщины первого класса.

```python
df.loc[
    (df["sex"] == "female") & (df["pclass"] == 1),
    ["age", "fare", "survived"],
]
```

Если после фильтрации нужно увидеть самые дорогие билеты:

```python
.sort_values("fare", ascending=False)
```

## Почему среднее бинарного признака = доля

Если `survived` закодирован как `0/1`, то:

```python
df.groupby("sex")["survived"].mean()
```

даёт долю выживших внутри каждой группы.

Это очень важный аналитический приём и он встречается постоянно.

## GroupBy

```python
df.groupby("pclass")["survived"].agg(["count", "mean"])
```

Здесь одновременно важно смотреть:

- `count` — размер группы;
- `mean` — долю выживших.

Нельзя интерпретировать процент, не понимая размер выборки.

## Пропуски

```python
df["age"].isna().sum()
```

Простой учебный вариант заполнения:

```python
median_age = df["age"].median()
df["age_filled"] = df["age"].fillna(median_age)
```

Но в реальном ML-проекте нельзя механически заполнять пропуски медианой на всём датасете до train/test split — это может привести к утечке данных.

## Производный признак

```python
df["is_child"] = df["age_filled"] < 16
```

Новый признак превращает повторяющееся условие в понятную категорию.

```python
df.groupby("is_child")["survived"].agg(["count", "mean"])
```

## Несколько уровней группировки

```python
df.groupby(["sex", "pclass"])["survived"].mean()
```

Для более удобного чтения:

```python
(
    df.groupby(["sex", "pclass"])["survived"]
      .mean()
      .unstack()
)
```

Так получается компактная таблица вида «пол × класс».

## Что важно не перепутать

Учебные различия между группами — это **описательные наблюдения**, а не доказательство причинности.

Например, если в конкретной выборке доля выживших у одной группы выше, из этого ещё нельзя автоматически заключить, что именно этот признак является причиной различия.

## Что запомнить

1. Перед анализом всегда проверяй пропуски и типы.
2. `.loc` удобно совмещает условие по строкам и выбор столбцов.
3. Среднее бинарного `0/1`-признака — это доля единиц.
4. Вместе с долями проверяй размеры групп.
5. `groupby` позволяет отвечать на большинство базовых вопросов к категориям.
6. `unstack()` помогает сделать многоуровневый результат читаемым.
7. Новый признак стоит создавать, если одно и то же условие используется многократно.
